# SelectorPatch 开发验证流程

## 概述

本文档定义了 SelectorPatch 项目的开发验证流程，确保代码修改后源码和二进制产物都能正常工作。

## 验证流程分类

### 1. 源码修改验证流程

当修改了 `src/` 目录下的源代码时，需要执行完整的验证流程：

#### 步骤 1: 源码验证
```bash
# 1. 激活虚拟环境
source venv/bin/activate

# 2. 使用源码直接运行测试
python src/main.py templates/全维度筛选.xlsx
python src/main.py templates/支持空筛选.xlsx

# 3. 检查输出结果
ls -la outputs/
```

#### 步骤 2: 重新构建二进制产物
```bash
# 构建所有平台版本
./scripts/build.sh

# 或者分别构建
./scripts/build.sh macos
./scripts/build.sh windows
```

#### 步骤 3: 二进制产物验证
```bash
# 测试 macOS 版本
./dist/app_macos templates/全维度筛选.xlsx
./dist/app_macos templates/支持空筛选.xlsx

# 检查输出结果
ls -la outputs/
```

### 2. 打包流程修改验证流程

当只修改了构建脚本 `scripts/build.sh` 或打包相关配置时，只需验证二进制产物：

#### 步骤 1: 重新构建
```bash
# 清理旧的构建产物
rm -rf dist/ build/ *.spec

# 重新构建
./scripts/build.sh
```

#### 步骤 2: 验证二进制产物
```bash
# 验证文件生成
ls -la dist/

# 测试功能
./dist/app_macos templates/全维度筛选.xlsx
./dist/app_windows templates/全维度筛选.xlsx  # 在 Windows 环境中测试
```


## 常见问题排查

### 1. 源码运行正常但二进制产物报错
- 检查 PyInstaller 的 `--add-data` 参数是否包含所有必要文件
- 检查 `--hidden-import` 是否包含所有动态导入的模块
- 查看构建日志中的警告信息

### 2. 变量作用域错误
- 检查是否有重复的 `import` 语句
- 确保模块导入在函数外部进行
- 避免在函数内部重新导入已导入的模块

### 3. 路径问题
- 确保相对路径在打包后仍然有效
- 使用 `os.path.dirname(os.path.abspath(__file__))` 获取正确的基础路径
- 检查配置文件和模板文件的路径
